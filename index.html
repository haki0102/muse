Kenapa harus sederhana?

Karena pengunjung cuma butuh beberapa detik untuk memutuskan. Halaman yang ringan dan jelas bikin pesanmu langsung sampai.

Cepat Dibuka

Satu file HTML tanpa beban berlebih. Halaman tampil hampir seketika, bahkan di koneksi yang pas-pasan.

Responsif

Tata letak menyesuaikan otomatis — enak dibaca di HP, tablet, maupun layar laptop yang lebar.

Mudah Diedit

Kode ditulis rapi per bagian: header, hero, fitur, FAQ, footer. Ganti teks dan warna tanpa pusing.

Ramah Mesin Pencari

Struktur judul dan meta description yang benar membantu halaman lebih mudah ditemukan di Google.

Mode Gelap Otomatis

Mengikuti pengaturan perangkat pengunjung — terang di siang hari, gelap dan nyaman di malam hari.

Tanpa Ribet

Tidak perlu database atau server khusus. Cukup unggah satu file, halaman langsung bisa diakses.

Mulai dalam 3 langkah

Dari file kosong sampai halaman tayang, prosesnya sesederhana ini.

1

Ganti isi halaman

Buka file index.html, lalu ubah judul, deskripsi, dan tombol sesuai produk atau jasamu.

2

Sesuaikan warna

Ubah variabel warna di bagian atas kode — misalnya --accent — dan seluruh halaman ikut berubah.

3

Unggah & tayang

Unggah file ke hosting favoritmu — misalnya gratis lewat GitHub Pages, caranya ada di bagian berikutnya.

Tayang gratis lewat GitHub Pages

Mau menyambungkan halaman ini ke GitHub? Simpan kodenya di repository, aktifkan GitHub Pages, dan halamanmu langsung punya alamat sendiri — gratis.

  1. 1
    Buat repository baruDi GitHub, klik New repository, beri nama misalnya landing-page, lalu buat.
  2. 2
    Unggah file index.htmlKlik Add file → Upload files, pilih file halaman ini, lalu klik Commit changes. Bisa juga lewat perintah git di samping.
  3. 3
    Aktifkan GitHub PagesBuka Settings → Pages, pada bagian Source pilih branch main dan folder / (root), lalu simpan.
  4. 4
    Halamanmu tayangTunggu sekitar satu menit. Halaman bisa dibuka di alamat https://username.github.io/landing-page/ — ganti username dengan nama akun GitHub-mu.
Alternatif: lewat terminal / git
# masuk ke folder proyek
git init
git add index.html
git commit -m "Landing page sederhana"
git branch -M main
git remote add origin https://github.com/username/landing-page.git
git push -u origin main

Setiap kali kamu mengubah isi halaman, cukup unggah ulang file-nya atau jalankan git add ., git commit, dan git push — GitHub Pages akan memperbarui halamanmu otomatis.

Sering ditanyakan

Hal-hal dasar yang biasanya ditanyakan sebelum memakai landing page seperti ini.

Apakah saya harus bisa coding?

Tidak harus mahir. Sebagian besar perubahan cukup mengganti teks di antara tag seperti <h1> dan <p>. Kalau mau mengubah warna, cukup edit variabel di bagian CSS paling atas.

Apakah halaman ini bagus dibuka di HP?

Ya. Tata letaknya responsif: kolom-kolom akan menumpuk rapi di layar kecil, menu berubah jadi tombol hamburger, dan semua tombol cukup besar untuk disentuh.

Bagaimana cara mengganti tombol WhatsApp / kontak?

Cari bagian dengan id="kontak" di dekat akhir file, lalu ganti tautan tombolnya dengan nomor WhatsApp, email, atau tautan formulir milikmu.

Bagaimana cara menyambungkan ke GitHub?

Buat repository baru di GitHub, unggah file index.html ini, lalu aktifkan GitHub Pages lewat Settings → Pages. Langkah lengkapnya ada di bagian GitHub Pages di halaman ini.

Apakah bisa ditambah foto atau video?

Bisa. Simpan file gambar di folder assets/, lalu tampilkan dengan tag <img src="assets/nama-file.jpg" alt="..."> di posisi yang kamu mau.

Siap bikin halamanmu sendiri?

Salin kode halaman ini, ganti isinya dengan ceritamu, lalu bagikan tautannya ke mana saja.
