# Landing Page Sederhana

Contoh landing page sederhana, bersih, cepat, dan responsif, dalam Bahasa Indonesia. Satu file HTML, tanpa proses build.

## Isi halaman

- Header dengan menu mobile
- Hero dengan pratinjau browser
- 6 kartu fitur
- Panduan 3 langkah
- Bagian GitHub Pages
- Bagian "Cocok untuk siapa"
- FAQ yang bisa dibuka-tutup
- Tombol salin alamat email
- Footer

## Cara melihat

Buka `index.html` langsung di browser, atau tampilkan online lewat GitHub Pages.

## Cara aktifkan GitHub Pages

1. Buka repo ini di GitHub, masuk ke **Settings > Pages**
2. Di **Build and deployment**, pilih **Deploy from a branch**
3. Pilih branch `main` dan folder `/ (root)`, lalu **Save**
4. Tunggu sebentar, lalu buka alamat yang diberikan GitHub Pages

## File

- `index.html` — halaman landing page, semua CSS dan JavaScript ada di dalam file ini
- `README.md` — file ini

## Cara edit

1. Edit teks, judul, dan kontak di `index.html`
2. Simpan, lalu refresh browser
3. Push lagi ke branch `main` kalau mau tampil di GitHub Pages
